## Skipped or changed, and why
- **CARTO map tiles → OpenStreetMap tiles** (S3). CARTO now returns an "API key required" image for every tile, and the project rules forbid API keys. OSM's standard tiles are greyed with CSS to keep the calm look.
- **No real photos.** We must not download or hot-link images. The app shows designed illustrations, and real photos can be dropped in via `public/photos/` (see its README).
- **No MP4 video.** The only `ffmpeg` available is Playwright's limited build (no H.264). See "Needs a human" for the one command.
- Nothing from the "cut list" in PLAN.md had to be cut.

## Known limitations (be honest about these in Q&A)
- Everything after "sign up" is **simulated**: no SMS, no real payment, no charger connection, no bank payout. Data lives only in the browser that uses it. Two people on different phones don't see each other's bookings; the presenter view and two tabs on one laptop do.
- **Reset demo** wipes the data in that browser only.
- The charging session plays in 25 seconds whatever the booked duration, and the battery level is an estimate.
- Pins of nearby spots overlap at the default zoom (Sai Kung, Kwun Tong/Kowloon Bay). Use the list or zoom in.
- The map needs internet for its tiles. Without it, the app falls back to the list automatically.
